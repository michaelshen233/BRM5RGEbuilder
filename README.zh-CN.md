# RGE Studio 中文版

用于 BRM5 Realtime Game Editor 的 Python / Flask 可视化指令编辑器。默认显示简体中文，可在页面右上角切换 English；语言选择会被记住。

## 启动

安装 Python 3.12 或更新版本，在项目文件夹中打开终端：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

然后打开 <http://127.0.0.1:5000/>。macOS / Linux 可用 `python3 -m venv .venv` 创建环境，再执行 `source .venv/bin/activate`。

## 使用方法

1. 创建项目，或导入你的 `BRM5RGE.xlsx`。也可以导入随项目附带的 `examples/workbook-library.json`；它包含从原表格提取的 198 条指令。
2. 选择指令类型，填写世界编号、对象 UID 或 `%别名` 及相应参数。
3. 使用“粘贴坐标与旋转值”输入 3 个坐标值，或 6 个坐标及旋转值。支持逗号或空格分隔。
4. 点击“保存指令”或“更新指令”，把草稿提交到项目序列。编辑时草稿会自动保存到本地，但只有已保存的指令会出现在序列导出中。
5. 调整顺序、复制指令，或导出 `.txt`，再粘贴到 Roblox 的 RGE 编辑器中。

指令库支持搜索名称、别名、世界编号、备注和指令内容。每条指令最多保留 30 个历史版本，可从序列中的历史按钮恢复。

## 中文界面与指令原文

- 世界编号为正整数，包括 `1231`。
- 爆炸参数采用你确认的顺序：**威力 → 半径 → X → Y → Z → 类型**。部分社区文档对前两个参数使用不同名称；应用保留你指定的含义及原始数值顺序。
- 机器人最后一个参数为朝向（度）；传送玩家的最后一个旋转参数可以留空，以保留表格中的简写。
- `trigger set` 末尾的 `true/false` 暂标为“触发标志”，具体作用尚未确认。
- `move`、`tween`、`Motar`、`C4`、`%hiddenelevator` 等实际指令词、类型名和别名不会被翻译。已有项目名称、备注及历史内容也保留原文。
- 数字按文本保存，保留长小数和 `-0`。中文项目名称可以用于导出的文件名。

原表格中 194 条指令符合已支持的格式，另外 4 条作为自定义指令保留供检查。导入过程只读取已保存的公式结果，不运行公式。若修改过表格公式，请先在电子表格软件中重新计算并保存。

## 保存与备份

项目、草稿和历史记录保存在当前浏览器、当前网址的本地存储中，不会自动跨设备同步。清除浏览器数据会删除这些记录。请定期使用“导出备份”，在新网址或其他设备上导入 JSON 备份。

切换语言只改变界面显示，不清空工作空间。表格和备份会导入为新项目，已有项目保留；文本指令追加到当前项目。

服务器在内存中处理表格上传和指令校验，不将工作空间保存到服务器文件中。本应用不连接 Roblox、不执行游戏指令，也不自动录制游戏过程。

## 稍后部署到 Vercel

1. 将项目放入 Git 仓库并在 Vercel 中导入。
2. 根目录设为包含 `app.py` 的目录，框架选择 **Flask**。
3. 不需要自定义构建命令或输出目录，直接使用项目中的依赖和 `vercel.json`。
4. 部署后打开新网址，再导入你的工作空间备份。

无需环境变量或数据库。`examples/` 中的私人表格指令默认不随 Vercel 发布。完整结构、测试方法和资料来源请参阅 [README.md](README.md)。

### 编辑器改进

新工作空间只有一个空白默认项目，已有项目会保留。每个项目新增自动保存的随手记，包含在 JSON 备份中，不包含在命令文本导出中。将命令粘贴到导入输入框，按 Enter 导入，Shift+Enter 换行。爆炸威力（伤害）和半径既可输入也可滑动调整，手动输入可超出滑块初始范围。直接修改实时命令即可同步受支持的参数和位置图，保存后更新序列。图中新增爆炸半径示意圈。
